# Скрипт для улучшения школьных показателей в электронном дневнике.

Данный скрипт используется в контексте приложения [электронный дневник](https://github.com/devmanorg/e-diary) с существующей БД.
Для заданного ученика скрипт менят оценки ниже "4" на оценку "5" , удаляет все замечания и может создать похвалу.  


### Как установить
Клонируем репозиторий:
```
https://github.com/sylaar/Django-ORM-lesson3.git
```
На сервере переходим в папку с файлом `manage.py`  
Копируем `script.py` в эту папку.  
Открываем из этой папки терминал и в нем пишем:  
```
python manage.py shell
import script
script.main('фильтр по ученику', 'фильтр по предмету')
```
Первый аргумент <фильтр по ученику> функции `script.main()` обязательный.  
Если необходимо создать похвалу, то задаем второй аргумент <фильтр по предмету>, т.к. она привязана к конкретному предмету.
